# TopoCNV

Official code repository for TopoCNV (topology-guided CN V delineation).

TopoCNV is a two-stage network for automated multi-branch trigeminal nerve (CN V) delineation on planning CT, intended to support perineural-invasion-oriented CTV and OAR definition in nasopharyngeal carcinoma radiotherapy.

Associated manuscript:

> Automated Trigeminal Nerve Delineation on Planning CT to Support Perineural-Invasion-Oriented Target Definition in Nasopharyngeal Carcinoma Radiotherapy
