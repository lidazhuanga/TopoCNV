# CNV 绿皮新实验计划：先证明 MRI 有用，再学习何时使用 MRI

## 定位与结论

- 投稿方向：Radiotherapy and Oncology，沿用现有154例队列；用户已选择允许CT+MRI推理。
- 本轮是新研究协议，暂称V5-Utility；不修改或覆盖P0、V4.0—V4.3的冻结计划、数据、预测和结果，也不继续工程重构。
- 目标有两层：首先超过同条件CT-only nnU-Net v2；更重要的是超过强CT+MRI普通融合、MMd及匹配计算量的简单集成。
- 不能保证创新性与Dice优势同时成立。可以保证的是：创新假设明确、对照公平、预先规定否决条件，不在负结果后继续堆模块或更换终点。

## 一、之前为什么没有成功

### 历史计划不是同一组实验

| 阶段 | 实际证据 | 应得出的结论 |
|---|---|---|
| P0：解剖memory与证据gate | 原GT的154例OOF：Full Dice 0.6049，去memory 0.6057，仅级联0.6089，nnU-Net v2为0.6579 | Full落后最强CT对照5.30个百分点；重新训练去memory没有损失，核心贡献尚未成立 |
| P0：固定融合消融 | 固定融合Dice 0.5842，但同时改变alignment范围 | 支持动态配置有作用，不能把差值全部归因于单一gate |
| V4.0：ROI与先验 | 开发Dice R0为0.6565、R1为0.6410；少19349个TP却只少8218个FP；基线ROI外FP仅占0.04% | 优化了几乎不存在的远处FP问题，却伤害召回；不再优先ROI裁剪 |
| V4.2：骨架召回 | 已完成三个开发折，SR=0.5和1.0均低于S0的Dice | 该损失没有通过Dice选择；它不是完整拓扑约束，部分距离指标改善不能替代主终点 |
| V4.2与V4.3未完成项 | D2′没有结果；V4.3查阅时刚开始开发 | 不能把未完成实验写成失败，更不能先认定普通多模态融合无效 |

**容易被忽略的证据：**

- P0 Full的HD95均值约51.27 mm，但中位数约5.13 mm，29/154例超过50 mm；这说明存在少数严重失败，不能只展示平均Dice或距离中位数。
- V4.0中94.2%的FP距离GT不超过5 mm，MRI引导标签区域召回偏低。下一轮应关注局部边界与信息利用，而不是默认需要更大ROI、更强拓扑项。
- 最新标签本体为1=CT可见、2=MRI引导、3=可能走行、4=路标；不能继续把class2解释为V2分支。主二值目标仍为1∪2∪3∪4。
- V4开发统计的91个case-fold观测仅对应73名独立患者，不能当作91个独立样本计算确认性置信区间。
- harm_v1改变了标签厚度，新增161320体素。其分数不能与原GT下的0.6579直接相减。
- MRI注册代码使用目标GT辅助ROI/中心定位。这是新实验必须清除的输入依赖，但尚不能据此量化历史成绩受影响多少。

**不应直接定为根因的猜测：** CT部分容积、跨病例gate阈值漂移、SR导致预测加粗、配准误差主导失败。这些需要逐例和受控实验支持，不能用当前重构代码倒推历史失败。

## 二、新方案的唯一主创新

### 研究问题

**MRI存在、清晰、配准看似正常，都不等于它在这个局部真的改善分割。能否直接学习“采用MRI修正相对于CT的净收益”？**

不是再做一个memory、attention或quality gate，而是把局部选择器的监督目标改为患者级交叉拟合得到的实际增量误差。

### 为什么可能改善Dice

1. 用强nnU-Net v2保留已经有效的CT预测，不重做弱主干。
2. 在MRI确实补充走行/边界信息的位置接受多模态修正，争取恢复FN。
3. 在多模态修正有害的位置退回CT，限制新增的近边界FP。
4. 优势必须在自然、未人工破坏的MRI上出现；压力测试只能解释机制，不能替代主结果。

### 文献边界

下列路线均已有先例，不能单独作为创新声明：

- 缺失模态训练：ModDrop++，MICCAI 2022，https://arxiv.org/abs/2203.04959
- 不完整多模态融合：mmFormer，MICCAI 2022，https://arxiv.org/abs/2206.02425
- 模态贡献不平衡：PASSION，ACM MM 2024，https://arxiv.org/abs/2407.14796
- 可靠性证据折扣：MICCAI 2022，https://arxiv.org/abs/2206.11739
- 错配感知融合：CAA-Seg，MICCAI 2025，https://arxiv.org/abs/2507.11886
- 质量退化与残差gate：CoReFuse-Med，2026，arXiv注明ACM MM接收，https://arxiv.org/abs/2609.10261
- 缺失模态反事实学习：CausalDisenSeg，2026预印本，https://arxiv.org/abs/2604.13409
- 公平强基线原则：nnU-Net Revisited，MICCAI 2024，https://arxiv.org/abs/2404.09556

拟议区别是**监督模型特定的MRI增量效用，并验证它优于质量门控、自由gate和简单集成**。不得宣称首次提出反事实分割，也不得把该分数解释成MRI的临床因果效应。

## 三、先把输入与比较标准固定

### 不依赖目标GT的MRI输入链

- 重新建立独立版本的配准缓存，只使用CT/MRI影像几何、影像生成的头部掩膜及跨模态相似性；目标标签不得参与初始化、优化、变换选择或上线拒收。
- 沿用既有刚体配准类型与图像预处理，不同时引入新形变配准，以免多因素改变。
- 有效区由原始MRI采集视野变换得到，不用非零强度或GT包围盒代替。
- 注册失败、MRI缺失和无有效重叠均记录原因并走CT回退；病例保留在主评价中。人工QA只能盲于目标标签进行，不按预测分数剔除病例。
- 增加输入依赖测试：删除或置乱目标标签后，配准变换、MRI缓存和有效mask必须不变。
- 所有新融合对照共用这一输入版本；旧GT辅助配准上的结果只能作为历史探索，不与新方法直接比较。

### 标签、划分与训练配方

- 主实验沿用当前冻结harm_v1二值Y标准，所有新臂按相同标签训练及评价；原始临床GT作为预先规定的敏感性评分，不能事后选择更漂亮的版本。
- 不重新标定harm_v1厚度规则；披露它曾使用全队列几何统计，不声称完全隔离的数据处理。原GT若出现明确退化，不能宣称临床改善。
- 本轮统一0/5为背景；不混用旧P0对class5的ignore规则。
- 沿用既有患者级outer fold与Train/Dev/Report清单，按患者隔离，冻结清单及hash；保留曾经探索全队列的事实。
- 主干、patch、spacing、优化器、增强、迭代预算沿用已冻结R0u的nnU-Net v2配置，不新增架构搜索。快照记录实际配置，而不是只记录一个实验名。
- 每臂同seed、同训练病例、同有效训练步数；使用统一final checkpoint，不在报告折挑best。C/MM/MMd仅允许预先规定的输入和模态丢弃差异。
- 概率阈值固定0.5，不新增硬ROI或按臂优化后处理；指标使用统一的FP敏感Dice和空预测HD95惩罚实现。

## 四、先做信息收益闸门，不直接训练新gate

### 三个必需基线

| 名称 | 输入与策略 | 用途 |
|---|---|---|
| C | CT-only nnU-Net v2 | 强CT参考与无MRI回退 |
| MM | CT+MRI+有效区mask，普通早期融合 | 判断加入真实MRI是否有收益 |
| F／MMd | 与MM同主干，加现有V4.3整例、截断与slab丢弃策略 | 强缺失模态对照，也是后续冻结多模态专家 |

先在既有fold0、1、2开发流程上各跑一个固定seed，最多9个基础训练；只有标签、输入缓存、split和全部训练配置hash一致的既有产物才可复用。

同时评估F输入真实MRI和零MRI的配对变化，防止把训练正则化收益误认为MRI信息收益。

### 闸门A

在自然MRI条件下：

- MM和F中较强者相对C平均Dice至少增加0.010，至少2/3开发折为正。
- F相对自身零MRI输出必须存在平均正增益，MRI引导区域召回不能系统下降。
- 均值按每折患者平均后等权汇总；显著性不把重复case-fold行当独立病例。
- 若增益不足0.005或多数折非正：停止新gate，优先检查无GT注册、MRI对齐与标签可解释性。
- 若为0.005—0.010：仅允许增加一个预先固定seed复核，不搜索新网络。

这是投资门槛，不是统计显著性、临床最小重要差异或保证成功的标准。

## 五、通过闸门后实现局部效用选择器

### 推理结构

C和F固定，不联合微调。输出概率为：

`p = p_C + v × q × (p_F − p_C)`

- `v`为MRI有效区，`q`为0到1的局部选择权重。
- 无MRI、注册失败时直接只执行C；有效区外取C。
- 所有臂使用一致阈值和后处理，确保完整缺失MRI时预测及导出与C一致。
- 该结构只能利用C/F已有信息，不能凭空恢复两者都漏掉的细节；若两专家错误高度一致，提前停止选择器路线。

### 交叉拟合监督

每个外层训练集合内部按患者二分：各用一半训练C、F，预测另一半，再交换。形成该训练集合的完整OOF预测；报告患者绝不用于专家训练、效用头训练或参数选择。

- 开发阶段只在既定Train部分生成效用监督；Dev用于选择和晋级。
- 最终报告阶段冻结全部规则，在outer Train+Dev内部重新交叉拟合；Report始终不进入生成链。
- 专家的训练步数与checkpoint规则预先固定，不用被预测的那半患者选模型。
- F还需生成同病例的零MRI预测；这是训练效用标签用的参照，正常推理不增加第三次分割前向。

对7.5 mm物理边长的局部窗口，按实际spacing取最近的奇数核，计算局部类别平衡CE；窗口同时有正负类时两类各占一半，仅有单类时按存在类计算。

`d_C = loss(C, Y) − loss(F_真实MRI, Y)`

`d_M = loss(F_零MRI, Y) − loss(F_真实MRI, Y)`

`delta = min(d_C, d_M)`

`L_q = abs(delta) × BCE(q, delta > 0)`

因此，正目标要求真实MRI同时优于CT专家和同一F的零MRI输出。目标离线生成、停止梯度；delta为零的窗口不提供权重。

**限制：** CE差不是Dice的可加分解；双参照可能过保守；权重q不是未经校准的“有益概率”。这些均通过开发集Dice和消融决定，不靠叙事解释。

### 最小实现约束

- 采用三层局部卷积效用头，隐藏通道16、16，输出1通道Sigmoid；不增加Transformer、memory或拓扑项。
- 输入固定为CT、MRI、valid、距FOV边缘距离、C/F概率、各自二值熵、局部MIND类跨模态自相似差异、原始MRI层间距。元数据须来自原始采集信息，不能读取标签。
- 质量信号仅为候选解释变量：不同模态正常的组织对比差异不能直接标作“不可靠”。
- 自然样本占一半；其余样本等分为MRI平移、厚层降采样恢复、噪声退化。平移幅度为1/2 mm，降采样倍数为2/3，噪声标准差为MRI稳健强度尺度的0.03/0.06；概率、幅度及seed在首轮前冻结。
- 每个退化样本重新计算F预测和实测delta；不得按扰动幅度手工赋予好/坏MRI标签，也不把扰动参数输入q。
- 第一版只训练q，不用最终分割loss反向修改C/F或效用标签。

## 六、必须通过的消融，而不是多跑弱对照

以下控制复用相同C/F专家，匹配q容量、训练病例和预算：

1. **常数融合**：C/F概率混合，权重从0、0.25、0.5、0.75、1中仅由Dev选定；控制双模型集成效应。
2. **自由gate**：同头、同输入，仅以最终分割损失训练；控制“只是多一个网络”。
3. **质量-only效用头**：同效用监督，仅开放覆盖、边缘、MIND及层间距信号，其余通道置零；控制“只是识别质量”。
4. **完整效用头**：全部输入与交叉拟合效用监督。
5. **位置破坏诊断**：在同覆盖/质量分层内、病例自身有效区打乱q，不跨患者交换MRI；检验局部选择是否必要。

不得用全队列跨病例MRI错排作为主对照，避免供体跨训练/报告边界及明显域外输入混淆。

### 闸门B

- 自然MRI上，完整方法相对MM及F分别至少增加0.010 Dice。
- 至少2/3开发折为正，没有一折下降超过0.010。
- 还需超过开发选定的常数融合和自由gate；若与两者差异在0.003以内，视为创新贡献证据不足，不把0.003当显著性阈值。
- 按质量分层后，q仍需区分正/负实测增量；类2召回不能被系统压低。
- 若只在人工严重退化上获益，或收益仅来自整体缩小预测/集成，停止该创新路线。

## 七、最终验证与论文可声称的范围

### 统计与报告

- 通过两个开发闸门后冻结方案；五折生成每患者一次Report预测，保证154名患者完整覆盖。
- 主分析为全部154例自然部署条件，另报MRI可用病例子集；不因MRI质量差、注册失败或分割失败剔除病例。
- 主指标：患者级Dice_Y。次指标：HD95、2 mm Surface Dice、TP/FP/FN、标签来源类别召回、空预测率及大距离失败率。
- 配对bootstrap以患者为cluster，重复10000次；同一患者的seed、扰动版本和双侧结果不可拆成独立样本。
- 主比较采用至少3个预先固定的配对seed，报告每seed差值及患者平均差值CI，不选择最好seed。病例bootstrap不能覆盖全部训练/设计不确定性，需明确披露。
- 完整方法对MM和F均为共同必要比较，同时超过匹配预算的常数融合，才支持“效用监督有增益”；不只挑一个较弱对照。
- 最终目标：相对MM和F的Dice增益95%CI下限均大于0；相对F的HD95差CI上限不超过1 mm。开发+0.010只是进入这一验证的条件。
- 原GT敏感性评分必须报告；若其结果与harm_v1相反，限制结论，不能只保留有利终点。

### 无MRI与压力测试

- 全154例移除MRI，检验概率、二值预测、后处理及导出均与C一致；明确“体素值一致”不等同于压缩NIfTI文件逐字节相同。
- 真实无MRI仅1例，因此全队列移除实验不是对大量真实缺失患者的充分外推验证。
- 覆盖、厚层、错配压力测试及质量分层预先冻结；自然MRI结果始终为主。
- GT可用于评价效用、几何误差和参考标签，但不得进入任何推理特征、配准或质量拒收输入。

### 投稿叙事边界

- 内部多折和多seed不等于新外部确认。全队列曾被探索过，不用“完全独立确认集”包装后续结果。
- 本轮优先证明对充分配置的nnU-Net v2与强多模态对照有效；未实际比较的方法不纳入“超过所有SOTA”的声明。
- 如主结论成立，再补直接相关的可靠性融合外部方法对照；不通过改弱对照制造优势。
- 编辑时间、临床可接受性和剂量学是独立临床终点；没有盲法临床评价，不声称减少工作量或改善剂量。

- MRI可用时需C/F两个分割前向，无MRI一个；报告参数、FLOPs/耗时和额外训练成本，不能与单模型对照隐瞒预算差异。

## 九、止损与交付物

**止损：** 任一闸门失败，保留负结果，不继续叠加memory、ROI、骨架、Transformer或联合训练来挽救叙事。唯一低风险备选是强MM/MMd加明确CT回退，转为多模态使用边界与临床可行性研究；若未达到创新和精度双目标，应明确承认，而非保证一定能投稿成功。

获准执行后的交付物：

- C/MM/F公平基线和MRI真实增量结果表。
- 交叉拟合效用标签、低容量选择器、最小消融与失败案例。
